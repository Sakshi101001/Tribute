# 🌟 Chhatrapati Shivaji Maharaj – Tribute Website 🦁  

A responsive and informative website dedicated to the legendary **Chhatrapati Shivaji Maharaj**, showcasing his life, bravery, and legacy — built using **HTML, CSS, JavaScript, and Bootstrap**, and proudly hosted on **AWS S3 ☁️**.

---

## 🚀 Project Overview  
This website is a humble tribute to the great Maratha King **Chhatrapati Shivaji Maharaj**, the founder of the **Swarajya**.  
It highlights various aspects of his journey and the empire he built, presented through a modern, responsive UI.

---

## 🏗️ Tech Stack  
- 🌐 **Frontend:** HTML, CSS, JavaScript, Bootstrap  
- ☁️ **Hosting:** AWS S3 (Static Website Hosting)  
- 💻 **Version Control:** Git & GitHub  

---

## 📂 Sections Included  
1️⃣ **Historical Overview** – Glimpse into the glorious life of Chhatrapati Shivaji Maharaj.  
2️⃣ **Mavlas (Brave Warriors)** – Showcasing the unsung heroes who fought alongside Maharaj.  
3️⃣ **Forts & Monuments** – Architectural masterpieces that symbolize Maratha pride.  
4️⃣**Movies Section** – Films inspired by Maharaj and his brave Mavlas.  
5️⃣**Books Section** – Collection of notable books written on the life of Chhatrapati Shivaji Maharaj.
